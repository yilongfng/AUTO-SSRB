# AUTO-SSRB：基于 Simple Star Rating Block（SSRB）的 WordPress 自动评分集成工作流程

## 1. 项目简介

AUTO-SSRB 是一套面向自托管 WordPress 网站的自动评分集成工作流程。

它将第三方评分区块插件 Simple Star Rating Block（SSRB）的显示能力，与 WordPress 文章自定义字段和单篇文章模板结合起来，使文章评分能够从自定义字段中自动读取，并由共享模板统一显示。

本项目分享的是一种可复现、可调整的 WordPress 集成方法，而不是一个独立的 WordPress 插件或软件产品。

## 2. 项目希望解决的问题

Simple Star Rating Block 可以在 WordPress 文章中显示星级评分。

在常规使用方式下，作者需要在文章正文中逐篇插入和配置评分区块。对于需要长期维护大量文章的网站，这种方式会产生重复操作，也不利于统一管理评分显示。

AUTO-SSRB 探索另一种方式：

- 作者在编辑文章时填写评分。
- WordPress 保存文章对应的自定义字段。
- 共享的单篇文章模板调用评分区块。
- 评分区块自动读取当前文章的自定义字段并显示结果。

这样，评分数据与评分显示位置可以分别管理，作者不必在每篇文章正文中重复插入评分区块。

## 3. 工作原理

当前参考实现由以下部分组成：

1. **评分显示：** 使用第三方 WordPress 插件 Simple Star Rating Block 0.3。
2. **评分数据：** 使用名为 `film_rating` 的文章自定义字段保存评分。
3. **编辑入口：** 作者通过 Gutenberg 编辑器的原生“自定义字段”面板填写文章评分。
4. **统一显示：** 在 WordPress 单篇文章模板中放置 SSRB 评分区块。
5. **自动读取：** 将评分区块配置为 `useCustomField=true`，使其读取当前文章的 `film_rating` 字段。
6. **星级渲染：** 评分区块根据字段值显示相应星级，包括半星。

整体关系如下：

~~~text
Gutenberg 编辑器
       |
       v
填写文章评分
       |
       v
WordPress 自定义字段
film_rating
       |
       v
单篇文章共享模板
       |
       v
Simple Star Rating Block
useCustomField=true
       |
       v
显示当前文章的星级评分
~~~

## 4. 已完成的实际验证

这套集成方式已经在一个自托管 WordPress 网站上完成实际部署和测试。

目前确认的结果：

- 使用 Simple Star Rating Block 0.3。
- 通过 `film_rating` 自定义字段提供评分数据。
- 评分区块使用 `useCustomField=true` 读取字段。
- 评分区块放置在单篇文章模板中。
- 已测试 4.5 和 2.5 两种评分。
- 两种情况下半星均能正常显示。
- 文章正文不需要逐篇手动插入评分区块。

这些结果来自当前参考实现的实际测试，不代表已经完成对所有 WordPress 主题、模板系统或文章类型的兼容性测试。

## 5. 适用场景

这套方法可以作为自托管 WordPress 网站的集成参考，尤其适用于：

- 需要为文章统一显示评分的网站。
- 希望将评分数据与文章正文分开管理的网站。
- 使用共享单篇文章模板、希望减少重复编辑操作的网站。
- 希望利用现有 WordPress 插件和自定义字段实现自动化展示的站点维护者。

虽然当前验证使用的是影评场景，但 `film_rating` 只是参考实现中的字段名称。其他内容类型可以根据实际需求设计自己的字段和显示方式。

## 6. 当前范围与限制

AUTO-SSRB 目前分享的是已经完成实际部署验证的集成流程。

以下事项尚不能视为已经得到验证：

- 与所有 WordPress 主题的兼容性。
- 与所有区块主题及模板系统的兼容性。
- 与不同文章类型和自定义字段方案的兼容性。
- 与其他评分插件的兼容性。
- 在不同 WordPress 环境中的完整复现情况。

实际使用时，需要根据网站采用的主题、模板结构和字段注册方式进行适配。

本项目不替代 Simple Star Rating Block。评分显示仍由该第三方插件负责；AUTO-SSRB 介绍的是围绕它建立的集成方法。
