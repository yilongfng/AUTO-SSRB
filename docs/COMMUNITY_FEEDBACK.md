# Community Feedback and Participation

## 1. Welcome

AUTO-SSRB is a practical WordPress integration workflow built around an existing third-party star rating plugin.

The project welcomes feedback, testing experiences, questions, and improvement suggestions from the WordPress community.

You do not need to be a plugin developer to participate. WordPress site owners, theme users, and developers interested in custom fields, Gutenberg, and template integration are all welcome.

## 2. What Feedback Is Welcome?

We welcome discussion and practical feedback about:

- Reproducing the integration workflow on other self-hosted WordPress sites.
- Adapting the workflow to different WordPress themes and template systems.
- Supporting different post types and custom-field configurations.
- Improving the way rating values are entered, stored, and displayed.
- Troubleshooting rating retrieval and half-star display.
- Making the integration instructions clearer and easier to follow.
- Identifying limitations or alternative implementation approaches.

Suggestions based on real testing experience are especially valuable.

## 3. How to Share Feedback

GitHub Issues can be used to report problems and propose improvements.

Please choose the appropriate issue template:

- **Feature Request:** for proposed improvements, new use cases, and compatibility ideas.
- **Bug Report:** for unexpected behavior, reproduction steps, and technical problems.

When reporting an issue, include relevant WordPress, plugin, theme, and template information where possible.

Do not include passwords, access tokens, private website data, or other sensitive information in public reports.

For general questions or experience sharing, use the project's available discussion channels if they are enabled.

## 4. Testing and Verification

Community feedback helps identify new possibilities, but a suggestion or an individual success report does not automatically establish general compatibility.

The project follows these principles:

- Distinguish proposed ideas from implemented changes.
- Distinguish individual reports from verified results.
- Record the environment and configuration used during testing when relevant.
- Do not claim compatibility with a theme, template system, or post type without sufficient testing.
- Update project documentation when a result has been reproduced and verified.

The current reference implementation has been tested with Simple Star Rating Block 0.3, the `film_rating` custom field, and the `useCustomField=true` setting. Its verified rating examples include 4.5 and 2.5, with half-star display working as expected.

These results describe the tested reference implementation, not universal WordPress compatibility.

## 5. Maintainer Response

The maintainer will review community reports and suggestions as time permits.

Where practical, reported problems may be investigated and reproduced. Proposed improvements may be evaluated against the project's existing workflow and documented limitations.

Not every suggestion can be implemented, and not every reported configuration can be independently tested.

When new behavior or compatibility is verified, the relevant project documentation can be updated to reflect the result.

## 6. A Shared Goal

AUTO-SSRB aims to make WordPress rating integration easier to understand, reproduce, and adapt.

Community participation helps the project learn from different WordPress environments and real-world use cases.

Thank you for taking the time to test, discuss, report, and improve this workflow.
